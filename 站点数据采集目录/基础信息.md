## 2、网站主题色与默认明暗模式

**结论：默认选择暗色。** 漂移题材与夜间赛道、轮胎烟雾、霓虹速度线天然匹配；近黑背景能让电光青突出可交互元素，橙色可作为“追逐者/危险”辅助色。亮色模式保留相同青色品牌识别，但降低饱和度并用深色正文确保对比度。

```css
/* 导航页主题色 - 亮色主题 */
--nav-theme: 188 78% 38%;       /* cyan-700，白底上对比度更稳 */
--nav-theme-light: 188 74% 48%; /* 更亮的电光青 */

/* 导航页主题色 - 暗色主题（默认） */
--nav-theme: 188 86% 52%;       /* electric cyan */
--nav-theme-light: 188 92% 65%; /* 更浅的电光青 */
```

推荐配套色：页面背景 `222 32% 7%`、卡片 `222 26% 11%`、正文 `210 20% 96%`、追逐/强调色 `24 95% 55%`。按钮、正文和背景组合仍应逐项进行 WCAG AA 对比度测试。

### 排序依据与本地化原则

- **英语优先**：Roblox 体验名、搜索导航词、更新公告与大多数跨地区社区沟通默认使用英语，也是最稳妥的 canonical 内容源。
- **巴西葡萄牙语第二**：巴西拥有庞大的 Roblox 与汽车游戏玩家群；用 `carros`、`drift`、`mapas`、`guia para iniciantes` 承接自然搜索，但保留品牌名 **Drift Tag**。
- **西班牙语第三**：可覆盖拉美和西班牙多个市场；核心词建议为 `coches`、`derrape`、`mapas`、`guía para principiantes`。
- **印尼语第四**：东南亚移动端 Roblox 社群活跃；核心词建议为 `mobil`、`drift`、`peta`、`panduan pemula`。
- **主题名不翻译**：四种语言的导航、标题和结构化数据均应保留正式品牌写法 **Drift Tag**，解释性译名只用于正文或关键词，避免用户误以为是另一款游戏。

> 实施建议：以 `en` 为默认 locale，并依次发布 `pt-BR`、`es`、`id`；每页设置自引用 canonical 与完整 `hreflang`，不要把机器直译页在未校对时加入 sitemap。

## 上线前必须复核

1. 从游戏创建者取得唯一 Roblox Experience URL、开发者/工作室名、发布日期和官方社交链接。
2. 在无登录窗口逐一打开 Roblox、Discord、YouTube 与所有素材链接，确认不是 404、私密、过期或年龄/地区拦截页。
3. 仅在 Roblox 官方 API 或体验页显示后再填写 Players Online、Visits、Favorites 等动态数字，并记录抓取时间。
4. 只发布开发者公告确认仍有效的兑换码；“未验证”不等于“无兑换码”。
5. 确认 Logo、截图、音乐、车辆外观和 Hero 图的使用授权，避免真实车标与第三方版权资产。
